Design system

The living reference, rendered from the actual tokens the site runs on. Colors and type are CSS custom properties in styles.css (the single source of truth), and Tailwind's @theme inline points every type and color utility (text-h1, bg-ember, …) at those same vars, so for color and type, what you see here and what ships can't drift. Spacing, radii, and shadows are documented from the same values, but they're literal tokens rather than live vars, so those stay in sync by hand. Flip the theme; drag the width.

Background grid

The whole site sits on a viewport-fixed lattice. 1px lines every 32px, painted at the --grid-line token (5% ink, which inverts per theme so it reads on light and dark alike). It is position: fixed with pointer-events: none at z-index: 0, so content scrolls over a grid that never moves. A top fade (--plaster to transparent) keeps the header area clean, and on fine-pointer devices a cursor glow lights the nearest lines in ember.

Spacing

One scale on a 4px base (--spacing: 0.25rem) with an 8px rhythm for most gaps and padding. Tailwind's p-*, gap-*, and m-* utilities all step in 4px units, so gap-4 is 16px. Each bar is drawn at calc(var(--spacing) * n), measuring the live token.

Elevation

Shadows are dark-on-light and reserved for surfaces that lift off the page: shadow-card-hover for the card lift on hover, plus the heavier shadow-media and shadow-video for hero imagery. Shown on a light surface, where these shadows are built to sit.

Icons

Every icon is a 24×24 inline SVG that paints with currentColor, so it inherits the text color and flips to ember on hover without a second asset. Two families share the frame: solid brand marks (fill) and line UI icons (2px stroke, round caps). Hover a tile to see the currentColor swap.
