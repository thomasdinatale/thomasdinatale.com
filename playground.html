The #1 real-world gotcha (learned live building this page): your styles.css line 4 has an unlayered global reset — * { padding: 0 }. Unlayered CSS beats everything inside a @layer, and all Tailwind utilities live in @layer utilities. So the reset silently zeroed every p-8 / px-26 until I put styles.css into a site layer ordered below utilities (see the <style> in this file's <head>). This exact issue is what makes people say "Tailwind isn't working" when adding it to an existing codebase.

The actual skill you're learning isn't memorizing class names — it's the judgment call in that last row. Tailwind is for the repetitive 95% (spacing, color, type, flexbox). Genuinely custom CSS (your gradient border) stays as a named component. Knowing which is which is the whole game.
